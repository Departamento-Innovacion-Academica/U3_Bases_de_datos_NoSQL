2.3.3 Actualización múltiple

Cuando varios documentos deben cambiar simultáneamente:

db.clientes.updateMany(
  {ciudad:"Bogotá"},
  {$set:{region:"Centro"}}
)

Actualiza todos los clientes coincidentes.

2.3.4 Reemplazo completo de documento

También puede reemplazarse el documento entero.

db.clientes.replaceOne(
  {_id:1001},
  {nombre:"Ana",
   ciudad:"Cali"}
)

Debe usarse con cuidado, pues campos omitidos se pierden.

2.3.5 Actualización en sistemas clave-valor

En Redis, actualizar suele equivaler a sobrescribir el valor asociado a una clave.

Ejemplo
SET cliente:1001 "Ana Torres - Medellín"

La clave conserva nombre, pero cambia contenido.

Consulta posterior
GET cliente:1001
