1.4.4 Manejo de joins

SQL destaca por relaciones complejas entre múltiples tablas.

Ejemplo SQL

SELECT c.nombre, p.total
FROM clientes c
JOIN pedidos p
ON c.id = p.cliente_id;

En muchos motores NoSQL tradicionales, los joins son limitados o se evitan mediante desnormalización.

Ejemplo documental

db.pedidos.find({cliente:"Ana"})

El pedido ya contiene datos necesarios.

1.4.5 Flexibilidad del esquema

SQL: Normalmente requiere definir estructura previa.

CREATE TABLE clientes(
  id INT,
  nombre VARCHAR(100)
);

NoSQL: Muchos motores permiten documentos variables.

{"nombre":"Ana"}
{"nombre":"Luis","telefono":"3000"}

Esto facilita la evolución rápida de aplicaciones.
