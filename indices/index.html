3.2.1 Índice simple

Es el índice creado sobre un solo campo. Se utiliza cuando las consultas filtran repetidamente por un atributo específico.

Ejemplo en MongoDB

db.clientes.createIndex({correo:1})

Consultas como:

db.clientes.find({correo:"ana@email.com"})

mejoran notablemente.

3.2.2 Índice compuesto

Se construye sobre varios campos y resulta útil cuando las consultas combinan filtros.

Ejemplo

db.pedidos.createIndex({ cliente_id:1, fecha:-1 })

Ideal para consultas como:

db.pedidos.find({ cliente_id:1001 }).sort({fecha:-1})

3.2.3 Índice único

Garantiza que no existan valores duplicados en un campo determinado.

Ejemplo

db.usuarios.createIndex( {correo:1}, {unique:true} )

Se utiliza en:

  • Correos electrónicos
  • Identificaciones
  • Códigos internos
