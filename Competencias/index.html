1

Fundamentos de bases de datos NoSQL

Comprensión general de los principios de las bases de datos NoSQL, incluyendo sus características principales, diferencias frente al modelo relacional y los distintos tipos de modelos de datos como documentales, clave-valor, columnar y grafos.

2

Conceptos básicos de modelado de datos

Conocimiento de cómo se estructuran los datos dentro de una base de datos, incluyendo la organización de documentos, colecciones, claves y atributos dentro de distintos modelos de almacenamiento.

3

Operaciones básicas de bases de datos

Comprensión de las operaciones fundamentales de manipulación de datos, como inserción, consulta, actualización y eliminación de registros dentro de un sistema gestor de bases de datos.

4

Conceptos básicos de consultas de datos

Capacidad para comprender la lógica de filtrado, selección y recuperación de información mediante consultas estructuradas, así como el uso de condiciones para acceder a datos específicos.

5

Principios de almacenamiento y gestión de datos

Comprensión general de cómo los sistemas de bases de datos almacenan, organizan y gestionan grandes volúmenes de información dentro de aplicaciones modernas.

6

Actitud analítica frente al manejo de datos

Disposición para analizar la forma en que las operaciones de consulta y manipulación de datos pueden afectar el rendimiento, la eficiencia y la disponibilidad de la información dentro de un sistema.
